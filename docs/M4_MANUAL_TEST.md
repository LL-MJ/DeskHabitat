# M4 导航与栅栏人工验收

## 初始场景

1. 运行 `npm run dev`。
2. 确认草地上显示一组 L 形木栅栏，栅栏相邻部分视觉上连续。
3. 在生活模式观察兔子，确认黄色调试路径只经过相邻的上下左右格。
4. 等待兔子移动到栅栏另一侧，确认它沿路径绕过栅栏，没有穿越阻挡格。
5. 确认左上角显示导航网格版本和重新寻路次数。

## 动态栅栏

1. 从托盘切换到“布置模式”。
2. 点击一个空草地格，确认该格增加木栅栏；再次点击确认栅栏移除。
3. 尝试点击兔子当前所在格，确认不会在兔子脚下新增栅栏。
4. 在黄色路径的后续格增加栅栏，再切回生活模式。
5. 确认导航版本增加，兔子放弃旧路径并绕开新栅栏或安全返回待机。
6. 横向或纵向放置多段栅栏，确认相邻围栏自动显示连接横杆。

## 稳定性

1. 保持生活模式运行至少 10 分钟，并多次进入布置模式增删栅栏。
2. 确认兔子始终位于可通行格，没有穿越栅栏、越界或长期卡住。
3. 确认终端和开发者工具没有未处理异常。

## 通过标准

- A* 能处理可达、不可达、绕路和起终点相同情况。
- 兔子仅沿四方向路径移动，不穿过阻挡格。
- 栅栏变化会使旧路径失效并触发安全重规划。
- 无有效路径或当前位置失效时，兔子能安全恢复而不持续卡死。
