# M5 需求与设施闭环人工验收

## 需求与设施

1. 运行 `npm run dev`，确认草地上显示一个食盆和两个水盆。
2. 确认左上角显示 `H`（饥饿）、`T`（口渴）、`E`（精力）以及食盆/水盆容量。
3. 观察需求数值，确认饥饿和口渴缓慢增加、精力缓慢下降，且数值始终位于 0–100。
4. 等待口渴达到阈值，确认兔子进入 `seekWater`，沿黄色 A* 路径前往可达水盆。
5. 到达入口格后确认状态变为 `drink`、口渴降低、水盆容量同步减少。
6. 第一个水盆容量耗尽后，确认外观变灰，兔子自动寻找第二个可达水盆继续喝水。
7. 等待饥饿达到阈值，确认兔子完成 `seekFood → eat → hunger_satisfied` 闭环。
8. 精力较低时确认兔子原地进入 `rest`，恢复后重新活动。

## 目标失效与暂停

1. 在兔子前往设施期间切换到布置模式，用栅栏封住该设施的所有入口格。
2. 切回生活模式，确认旧路径失效；兔子寻找其他可达设施，或安全回到待机而不穿越栅栏。
3. 切换暂停模式，记录位置和 H/T/E 数值，等待至少 10 秒。
4. 确认暂停期间位置、动画、需求和设施容量均不变化；恢复后继续模拟。

## 通过标准

- 饥饿、口渴和精力始终保持在 0–100。
- 食盆和水盆拥有容量及明确的空置外观。
- 兔子能够完成寻路、使用设施、恢复需求的闭环。
- 设施耗尽、不可达或失效时，兔子能更换目标或安全退出行为。
- 暂停模式完全停止模拟，不补算暂停期间的帧。
