# M8 桌面体验加固人工验收

自动检查完成后再启动应用，避免开发监听器在修改源码期间反复弹出窗口。透明桌面行为必须在真实 Windows 环境中测试。

## 1. 输入穿透安全（高优先级）

1. 在生活模式下，将鼠标快速划过草地、兔子和栅栏，并连续操作下方的浏览器或文件管理器。
2. 进入布置模式，再点击另一个普通窗口使 DeskHabitat 失去焦点。
3. 从托盘进入布置模式，再选择“强制恢复鼠标穿透”。

通过标准：生活模式不长期吞掉点击；布置窗口失焦后自动返回生活模式并恢复穿透；托盘恢复入口始终有效。

## 2. 渲染异常恢复（高优先级）

1. 在开发调试窗口中打开任务管理器，结束 DeskHabitat 的一个 Renderer 子进程，不要结束主进程。
2. 立即尝试操作下方窗口。
3. 等待渲染层自动重载。

通过标准：渲染异常后立即恢复鼠标穿透；渲染层最多自动恢复两次，不进入无限重启；主进程与托盘仍可退出。日志中记录退出原因。

## 3. 睡眠、锁屏与恢复（高优先级）

1. 在布置模式下锁屏再解锁。
2. 正常睡眠计算机，等待片刻后唤醒。
3. 检查窗口位置、透明背景、世界缩放和模式。

通过标准：锁屏/睡眠时先恢复穿透并请求保存；恢复后进入生活模式、窗口重新匹配工作区，模拟不会追赶大量历史帧。

## 4. 显示器与 DPI（高优先级）

依次检查 100%、125%、150% 和 200% 缩放；条件允许时连接双显示器，并把副屏放到主屏左侧形成负坐标。

1. 从托盘切换目标显示器。
2. 修改缩放、分辨率或任务栏位置。
3. 拔掉当前目标显示器，再重新连接。

通过标准：窗口、等距地块和点击坐标一致；目标屏消失时回退主显示器并更新设置；变化期间恢复穿透，不锁住桌面。

## 5. 日志与首次引导

1. 全新设置首次启动时，确认只显示一次 Windows 托盘气泡提示，不弹出遮挡工作的对话框。
2. 使用托盘“使用提示”确认可以再次查看说明。
3. 检查 Electron `userData/logs/desk-habitat.log`。

通过标准：日志包含启动、模式、显示器、保存和异常信息，不记录剪贴板或其他应用内容；单文件达到约 512 KB 后轮转，保留最多三代历史日志。

## 6. 帧率与资源

1. 使用托盘在 30 FPS 与 60 FPS 之间切换，重新启动后确认设置保留。
2. 反复切换模式、调整窗口和热重载至少 20 次。
3. 退出后确认没有残留 DeskHabitat Electron 进程。

通过标准：生活模式帧率设置即时生效；退出时清理定时器、Pixi ticker 和渲染资源；没有持续增长的事件监听或重复模拟。
