# M6 布置模式人工验收

## 工具栏与放置

1. 运行 `npm run dev`，从托盘切换到“布置模式”。
2. 确认左下角出现“选择、栅栏、食盆、水盆”工具及“旋转、删除、取消”操作。
3. 选择“食盆”或“水盆”，移动鼠标，确认合法格显示绿色预览，重叠、设施格、兔子格等非法位置显示红色预览。
4. 在绿色格单击，确认设施被放置并成为选中对象；在红色格单击确认不会创建对象。
5. 尝试将设施放在地图边缘且所有入口都被阻挡的位置，确认放置被拒绝。

## 选择、移动、旋转和删除

1. 切换“选择”工具，单击一个设施，确认其地块显示蓝色选中边框。
2. 按住选中设施拖到绿色目标格后松开，确认设施移动、原格释放且导航版本变化。
3. 拖到红色非法格后松开，确认移动被取消，设施仍在原位。
4. 点击“旋转”或按 `R`，确认盆内白色方向标记旋转 90°。
5. 点击“删除”或按 `Delete`，确认设施消失、占用格释放，兔子不会继续使用已删除目标。
6. 按 `Esc` 或点击“取消”，确认当前拖动/预览被取消且已确认对象不受影响。

## 栅栏与模式退出

1. 选择“栅栏”工具，确认连续拖动、候选格延迟、转弯、闭合和孤立柱清理仍正常。
2. 尝试用栅栏堵住食盆或水盆的最后一个入口格，确认该格不会生成栅栏。
3. 选中栅栏柱后点击“删除”，确认柱及失去连接的孤立端柱被清理。
4. 切回生活模式，确认工具栏和预览消失、鼠标恢复穿透、兔子针对最新布局重新规划。

## 通过标准

- 用户可以通过明确工具完成栅栏、食盆和水盆的放置。
- 重叠、越界、兔子占用及无入口设施均不能确认。
- 设施可以选择、拖动、旋转和删除。
- 取消操作不改变已确认布局。
- 布局变化使导航和动物目标安全失效，退出布置模式后恢复桌面操作。
