# M1 桌面体验人工验收

M1 涉及 Windows 透明窗口、鼠标穿透和系统托盘，不能只依赖自动化测试。请在 Windows 10/11 上完成以下检查。

## 固定调试窗口

1. 运行 `npm run dev`。
2. 确认出现居中的 900×600 无边框棋盘格调试窗口。
3. 从系统托盘打开 DeskHabitat 菜单，切换“布置模式”。
4. 确认底部模式栏可点击，并能切换生活、布置和暂停状态。
5. 在布置模式按 `Ctrl+Shift+P`，确认窗口恢复鼠标穿透。
6. 从托盘选择“退出 DeskHabitat”，确认所有 Electron 进程退出。

## 桌面覆盖窗口

在新的 PowerShell 中运行：

```powershell
$env:DESK_HABITAT_DESKTOP_WINDOW = "1"
npm run dev
```

1. 确认窗口覆盖主显示器工作区，但不覆盖任务栏。
2. 确认背景透明、没有系统边框、任务栏中没有 DeskHabitat 窗口按钮。
3. 在生活模式下点击桌面图标和普通应用，确认点击能穿透覆盖窗口。
4. 从托盘进入布置模式，确认覆盖窗口能够接收鼠标输入。
5. 切换暂停和继续，确认状态提示同步变化。
6. 切换“置于普通窗口上方”，确认覆盖层级发生变化且不遮挡任务栏。
7. 改变主显示器分辨率或缩放比例，确认窗口重新贴合工作区。
8. 连接或断开第二块显示器，确认窗口仍位于主显示器工作区。
9. 再次启动 DeskHabitat，确认没有创建第二个实例。
10. 从托盘选择“退出 DeskHabitat”，确认应用完全退出。

## 通过标准

- 上述项目全部通过。
- 操作过程中没有出现无法恢复的鼠标拦截。
- 开发者工具与终端中没有未处理异常。
