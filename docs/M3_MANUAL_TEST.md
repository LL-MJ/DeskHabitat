# M3 兔子与基础模拟人工验收

## 功能检查

1. 运行 `npm run dev`，确认草地上显示一只程序绘制的兔子。
2. 等待约 30 秒，确认兔子会在待机和随机游荡之间切换。
3. 确认移动时兔子的朝向会随方向改变，身体有轻微步行动画。
4. 确认兔子的脚始终落在草地范围内，没有越界。
5. 确认左上角调试信息显示模拟频率、兔子状态和朝向。
6. 从托盘切换到“暂停”，确认兔子的位置和动画停止；恢复生活模式后继续活动。
7. 切换到“布置模式”，确认模拟暂停，窗口和模式按钮仍可正常操作。
8. 缩放窗口，确认兔子随世界保持正确位置和深度关系。

## 稳定性检查

1. 在生活模式连续运行 30 分钟。
2. 确认兔子持续活动、没有越界或卡死。
3. 确认任务管理器中内存没有持续明显增长。
4. 确认终端和开发者工具中没有未处理异常。

## 通过标准

- 兔子在地图内持续进行待机和随机游荡。
- 朝向及动画与移动状态一致。
- 暂停和布置模式不会推进模拟。
- 30 分钟运行没有明显内存增长或未处理异常。
