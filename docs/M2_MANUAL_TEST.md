# M2 等距世界人工验收

## 固定调试窗口

1. 运行 `npm run dev`。
2. 确认窗口中央显示完整的 8×6 菱形草地区域，没有被窗口边缘裁切。
3. 确认每个地块显示网格线和 `x,y` 坐标，左上角显示 FPS、地块尺寸和渲染器信息。
4. 拖动窗口边缘改变尺寸，确认草地保持居中并在空间不足时等比缩小。
5. 从托盘切换生活、布置和暂停模式，确认草地不偏移或重建闪烁。

## 桌面覆盖窗口

```powershell
$env:DESK_HABITAT_DESKTOP_WINDOW = "1"
npm run dev
```

1. 确认草地在主显示器工作区中央以原始尺寸显示。
2. 改变分辨率或系统缩放，确认 Canvas 清晰且草地重新居中。
3. 确认透明区域仍可透出桌面，地块以外没有不透明背景。

## 打包模式

1. 运行 `npm run dist:win` 并启动生成的应用。
2. 确认草地仍正常显示。
3. 确认不显示坐标、调试网格和 FPS 信息。

## 通过标准

- 等距草地完整、清晰、居中且比例正确。
- 窗口和 DPI 变化后没有裁切、拉伸或明显模糊。
- 调试信息只出现在开发调试窗口中。
- 终端和开发者工具中没有未处理异常。
